# 12-Lead ECG AI Analysis Project

This project leverages a deep learning model developed with PyTorch to analyze 12-lead ECG data. Initially trained to predict age and sex from ECG recordings, the model is designed to be fine-tuned for various diagnostic tasks to assist cardiologists in detecting and interpreting cardiac abnormalities.

## Getting Started

Follow these instructions to set up the project on your local machine for development and testing purposes.

### Prerequisites

Before you begin, ensure you have the following installed:
- Python 3.8 or later
- PyTorch
- Other dependencies (listed in `requirements.txt`)
